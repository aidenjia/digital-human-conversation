# 实时数字人页面自适应布局验收

日期：2026-10-21

## 变化

- PCM / WebRTC 共用的实时页面使用可用窗口宽高，取消该页原有 800px 页面、640px 人物面板限制。
- CSS 视口宽度至少 1024px 时约 3:2 分栏，人物居左、配置/对话及操作区居右；画布填充人物面板剩余空间。
- 小于 1024px 时上下排列，允许页面纵向滚动；会话区域有界，字幕内部滚动。
- 正常桌面输入和操作区不随字幕滚走；极矮桌面窗口允许会话面板整体内部滚动，不裁掉底部按钮。
- 字幕更新只设置字幕容器 scrollTop，不再使用 scrollIntoView 滚动祖先。
- 样式限定 `.realtime-app`，旧版页面不变；媒体、模型、动作冷却、传输 hooks 和后端未修改。

## Chrome 实测

浏览器当前缩放影响 CSS 视口与请求的测试尺寸，以下均记录实际 CSS 像素，不把外部请求尺寸当作实测尺寸。

| 实际视口 | 布局及结果 |
| --- | --- |
| 1745×982 | 页面约 1704px、人物面板约 984px、对话面板约 656px；人物画布约 983×619，无横向溢出。改动前同视口页面 800px、人物 640px。 |
| 1242×698 | 左右分栏；人物约 700px、对话约 467px；配置可以内部滚动，连接后的输入框和操作区位于可视范围。 |
| 698×931 | 上下布局，无横向溢出，配置和人物操作可达。 |
| 355×767 | 上下布局，无横向溢出；滚动页面到会话区域后输入框可见。真实第二轮回复使字幕 scrollHeight=636、clientHeight=401、scrollTop≈235；整页 scrollY 在回复前后均为 800，输入框上下位置不变。 |
| 1309×300 | 人物面板内部滚动；修复低高度底部按钮裁切，会话面板 overflow-y=auto，clientHeight=170、scrollHeight=318，控件可通过面板滚动访问。 |
