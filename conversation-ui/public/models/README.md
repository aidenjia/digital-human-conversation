## Local setup

Supply your authorized copy as `conversation-ui/public/models/avatar-sample-2.vrm` before launching the default character or running the real-model skeleton tests. The approximately 18 MB binary is ignored by Git; a fresh checkout does not include it. The browser's “导入 VRM” control can instead load another local character without uploading it. Real-model arm/wave tests specifically require the named sample file; building the frontend does not require the binary.

Includes A/I/U/E/O, blink, emotions and 54 humanoid bones. The client maps its custom Surprised expression separately.
