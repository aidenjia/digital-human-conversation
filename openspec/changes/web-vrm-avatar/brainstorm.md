Use Three.js, React Three Fiber and VRM with playback-driven amplitude mouth animation, local idle behavior, expression previews, simple gestures and barge-in coordination.
Preserve the existing conversation audio and server protocol. Use local VRM import because no licensed character asset exists in the repository.
