## Why

Add a lightweight visible conversation partner to the existing realtime browser client on integrated graphics.

## What Changes

- Introduce a locally rendered VRM stage, local file import and a geometric fallback character.
- Analyze WebRTC remote audio and scheduled PCM playback without duplicating audible output.
- Coordinate amplitude mouth motion, idle motion, expression previews and existing action events.
- Reset facial state and release audio/model resources on interruption and teardown.

## Capabilities

### New Capabilities
- `web-vrm-avatar`: Browser character rendering, playback mouth animation and action coordination.

### Modified Capabilities
None. Server API contracts remain unchanged.

## Impact

Realtime React pages, client media services, npm dependencies, and additive response lifecycle/identity events in both Java relays. Existing audio payloads remain unchanged.

## Non-goals

Photorealism, phoneme recognition, automatic semantic emotions, complete dance assets, legacy ConvoAI avatar integration, and guaranteed device performance.
